<p class="tg-eyebrow">Why trust it</p>
<h2 class="tg-h2">Checked against the tools you already believe.</h2>
<p class="tg-lede">A scientific library is only as good as its agreement with the references. Every package ships a comparison suite that runs its own results against the Python or R equivalent on shared problems. These are measured agreements, not aspirations.</p>
